## 截图要求

- 截图必须来自**微信开发者工具的真实运行界面**，不使用 AI 生成或伪造的运行效果图
- 截图不得包含以下内容：
  - OpenID
  - Token
  - AppSecret
  - 个人敏感信息（真实姓名、手机号等）
  - 服务器 IP / 域名等服务器信息
- 截图中如出现测试数据，应使用明显的示例数据
- 图片放入本目录后，在 README.md 的「项目截图」章节替换对应占位内容
